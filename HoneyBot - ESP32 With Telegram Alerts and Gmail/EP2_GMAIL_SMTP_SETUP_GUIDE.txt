HOW GMAIL SMTP WORKS (Technical Explanation)
═══════════════════════════════════════════════════════════════════════════

For the curious, here's what the code does:

PROCESS:
1. ESP32 connects to smtp.gmail.com:587 (Gmail's SMTP server)
2. Initiates TLS encryption (STARTTLS command)
3. Authenticates with email + app password (base64 encoded)
4. Constructs email headers (From, To, Subject)
5. Sends email body
6. Closes connection

ADVANTAGES:
• No middleman (IFTTT)
• Direct control over message formatting
• Real SMTP protocol (what enterprise systems use)
• Perfect learning project for understanding email
• Completely free and reliable

SECURITY NOTE:
In production code:
• Never hardcode credentials (use secure storage)
• Use proper certificate validation (we use setInsecure() for testing)
• Never expose App Passwords in public code

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEM: "Failed to connect to SMTP server"
FIX:
1. Check internet connection (ping google.com from another computer)
2. Verify Wi-Fi credentials are correct
3. Try restarting ESP32 (press EN button)
4. Check firewall not blocking port 587
5. Try using port 465 instead (modify smtp_port = 465)

PROBLEM: Email arrives but looks garbled
FIX:
1. Gmail sometimes has character encoding issues
2. Try changing email content to plain ASCII (no emojis)
3. Check "Content-Type: text/plain; charset=UTF-8" is in code ✓

PROBLEM: "Authentication failed" error
FIX:
1. Verify 2-Factor Authentication is ENABLED
2. Check app password (not regular Gmail password)
3. Check password is copied exactly with spaces
4. Try creating a new app password
5. Verify email_sender matches Gmail account

PROBLEM: Emails coming in hours later
FIX:
1. Gmail queues emails sometimes
2. This is normal for first email
3. Subsequent emails should arrive faster
4. You can whitelist ESP32 in Gmail filters if needed

PROBLEM: Too many emails arriving too fast
FIX:
1. This is normal - ESP32 sends one per attack
2. The 5-second cooldown prevents spam when scanning multiple ports
3. In Serial Monitor you'll see "[ALERTS] Cooldown active" for skipped ones
4. Gmail will thread them together in conversation view
